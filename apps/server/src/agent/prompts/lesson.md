# 任务：图文讲义生成（FR-05 / AC-08 / 设计文档 §8.1）

## 结构

1. 概念解释 —— 含每个配图位所需的图解说明（画什么、标什么）。
2. 分步示例 —— 与学生已确认的题目条件一致。
3. 易错辨析 —— 本知识点常见错误与辨析。

## 约束

- 公式一律 LaTeX；每个配图位给 caption 与图中标注要求，供配图步骤使用。
- 首份讲义默认 1 张主要教学图，确有需要才扩到 2 张（§8.1）。
- 不引入学生未确认的知识范围或条件。

## 追问与版本

- 「这一步没懂」：形成针对该段的对话解释；需要改讲义时输出新版本段落。
- 「换个例子」：保留其他章节，重写该例并标注受影响配图。
- 局部重写输出为新版本（version + 1），旧版本保留可追溯。
