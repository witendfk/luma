# 任务：图文讲义生成（FR-05 / AC-08 / 设计文档 §8.1）

## 结构

1. 概念解释 —— 用短文解释关键概念。
2. 分步示例 —— 与学生已确认的题目条件一致。
3. 易错辨析 —— 本知识点常见错误与辨析。

## 约束

- 公式一律 LaTeX；正文与图解步骤中的公式、条件和结论保持一致。
- 同一请求中生成真实数学示意图的结构化数据 graphic，并配 2 至 3 条看图说明。不能把文字编号步骤当作图示。
- 二次函数使用实际系数绘制曲线、对称轴和顶点；几何题按已知关系绘制点线。文字必须对应图中对象。
- 只给提示时隐藏顶点数值等答案信息；主动要求完整解析时才展示数值。
- 图解只复述并组织本次讲过的关系，不补充未讲结论；适配窄屏纵向阅读。
- 不输出 HTML、SVG、图片 URL 或文件引用；不要为教学讲义调用独立图片模型。
- 不引入学生未确认的知识范围或条件。

## 追问与版本

- 「这一步没懂」：形成针对该段的对话解释；需要改讲义时输出新版本段落。
- 「换个例子」：保留其他章节，重写该例及对应图解内容。
- 局部重写输出为新版本（version + 1），旧版本保留可追溯。
