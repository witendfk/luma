# 数学图示契约：生成、局部修订与复核共用

每幅图只服务一个明确卡点。图中对象、操作与正文逐一对应；区分顺序示意、数量图和空间关系。不能新增未确认条件，学生错误尝试须标明为待检查，不当作事实。

关键关系直接画在图内，不能靠图注补齐缺失的方向、操作或必要标注。示意位置不代表数值大小或实际长度；不把普通连接箭头当力、因果或反应机理。当前只交付数学，不假称已支持物理/化学专用图。

## 可用graphic数据

只生成下列JSON数据，不输出HTML、SVG、图片URL。未支持的关系不能套无关图。节点标签使用纯文本/Unicode（如a₁），公式正文仍用LaTeX。

操作链的label只放单行节点名（如“第1项”或“a₁”），禁止换行、反斜杠、美元符号和花括号；不要把“起点/尚未增加”等说明拼入节点名。渲染器画的是圆点、相邻箭头、运算标注和独立“起点”标记，不是方框；正文按实际对象称呼。“尚未增加”在正文/steps解释即可。复核只能要求协议能表达的实质修正，不要求新增徽标、任意图内注释、方框或其他未支持形状。

- **操作链 operation_chain**：数列项与间隔、相邻状态的加减乘除变化优先用此型，不用geometry冒充。格式：`{"kind":"operation_chain","caption":"说明图的目的","nodes":[{"label":"a₁"},{"label":"a₂"},{"label":"a₃"}],"operations":[{"operator":"add","operand":2},{"operator":"add","operand":2}]}`。2～8个节点，label唯一且1～12字符；第i次操作从第i个节点到下一个节点，操作数必须等于节点数减一；operator仅add/subtract/multiply/divide，operand是有限数值，不可除零，数值绝对值≤10000且普通字符串长度≤12。每条连接自动有箭头和运算标注，首节点标起点，位置只表示顺序。渲染器按节点数及标注宽度自动布局：至多5个短标签优先横排，较多节点、长标签或长运算改用纵排；不缩小关键字号硬塞。模型不要把正文写死成“上方/下方”，用节点名和箭头指代。可选节点value仅用于确有必要且已获准显示的数值，填写时必须符合全部前序操作；省略则不显示、不自动补出。理解间隔次数不必把原题各项数值提前填完。操作链只承诺这些四则变化，不能把一般因果/化学反应用此表达。
- **二次函数 quadratic**：`{"kind":"quadratic","a":1,"b":0,"c":0,"bounds":{"xMin":-3,"xMax":3,"yMin":-1,"yMax":10},"xLabel":"x","yLabel":"y","caption":"观察曲线","revealValues":false}`。系数用实际关系，a非零，范围包含坐标轴和顶点。xLabel/yLabel为1～12字符纯文本，与正文一致；例如y=t²使用xLabel=t。未设标签默认x/y。仅提示阶段revealValues=false；隐藏顶点数值不代表正文可以泄露原题最终答案。
- **几何 geometry**：`{"kind":"geometry","caption":"按题意说明关系；必要时注明非按比例","points":[{"x":0,"y":0,"label":"A"},{"x":1,"y":1,"label":"B"}],"edges":[[0,1]]}`。2～8点，标签1～24字符非空，连线只引用已有点。坐标需满足所声明关系，不能凭视觉推断未给出的垂直/等长等；当前不支持自动角标、单位与所有几何约束的程序证明。
- **有限映射 mapping**：`{"kind":"mapping","inputLabel":"输入 x","outputLabel":"输出 y","pairs":[{"input":-1,"output":1},{"input":1,"output":1}],"caption":"实际对应关系"}`。2～8个数值对，输入唯一、输出可重复；程序去重输出并保留每条箭头。正文选用的有限输入要列全且输出正确，不用连续曲线代替离散对应关系。

## 发布前四项检查

1. 科学正确：源条件、变量含义、定义域、公式与数值成立；布局不暗示不存在的数量/空间关系。概念例子可用，但须与原题区分。
2. 图文一致：正文提到的对象与关键关系在实际PNG中找得到；节点、间隔、运算与方向逐项对应。操作链既检查数量，也核对每次运算是否符合当前题目，schema通过不等于关系正确。
3. 教学有效：图中能直接读到本次卡点的关键关系。数列图必须看得到每段公差变化，而非五点四线加长篇图注；纯装饰或关键关系缺失不能发布。
4. 手机可读：查看最终PNG，标注不能重叠、裁切或小到无法辨认；颜色不能是唯一解释。装饰性偏好不触发付费修复，关键标注缺失/不可读才需修复。

保留当前完整答案权限：可解释必要中间关系，不直接泄露未授权的最终答案。检查失败指出具体章节/图及最小修复点，沿用现有一次共享修正额度；不能无限重试。不因旧图协议仍可解析而要求覆写所有历史材料。
