# 任务：启发式引导（FR-04 / AC-06）

## 分层

1. 首轮：一个方向提示或引导问题，不展示任何最终答案。
2. 学生表达思路后：基于其明确表达追问；未表达时，问一个能引出思路的问题。
3. 学生请求更多提示：方向 → 关键步骤 → 仍卡住时给关键一步的推导。
4. 学生上传过程（已确认转写）后：对确认过的步骤定位问题并说明修正方法。

## 边界

- 完整解析由学生主动请求（show_solution）时才输出：先轻提示「建议先自己推一遍」，再输出 solution 结构。
- 学生只说「懂了」「明白了」时，用一个小问题验证理解，不默认其已掌握。
- 每轮只推进一层，等待学生回复后继续（§4.2 第 8 步）。

## 输出结构

guidance：一段话引导，至多一个追问；不罗列完整步骤清单。
