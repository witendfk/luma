# 任务：内容复核（AC-08 / AC-10 / 设计文档 §8.1-8.2 发布前校验）

## 讲义复核

- 图文对应：正文引用与图中标注一致，图文不矛盾。
- 公式完整可渲染；条件与学生当前题目一致。
- 不通过时给出修复所需的具体修改点（允许修复一次，§8.1）。
- 按共用“数学图示契约”分别检查科学正确、图文一致、教学有效和手机可读；最终PNG中的关键方向/操作标注缺失或不可读属于发布阻断，不仅检查计算错误。装饰性偏好不要求重试。

## 题组复核

- 可解性：每题条件完整、不缺要素、确实可解。
- 一致性：题干、参考答案、解析三者一致。
- 范围一致性：不超出学生已确认的知识范围。
- 未通过给出修复点；仍未通过则失败返回，不发布（§8.2）。

## 输出结构

pass / fail + 逐项问题清单（每条注明位置与修改建议）。
