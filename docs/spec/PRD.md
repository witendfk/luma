# Luma 产品需求文档（PRD）

版本：V3.3 竞赛体验版。整理日期：2026-11-05。

**职责：定义产品为谁解决什么问题、业务流程、功能范围与业务约束。** 页面细节见 [交互设计](../design/interaction.md)，技术实现见 [系统设计](../design/architecture.md)，验收条件见 [验收规格](acceptance.md)。本文不记录开发状态或测试结果。

| 项目 | 定义 |
| --- | --- |
| 用户 | 高中学生，首期以高一数学内容验证 |
| 形态 | 个人主体微信小程序，体验版交付 |
| 核心价值 | 提问、启发引导、模型图文讲解、同类练习、个人错题回看 |
| 模型策略 | 服务端统一配置 GPT，学生端不提供模型设置 |
| 交付目标 | 三周竞赛版本；老师作为体验成员扫码独立操作 |

## 1 产品目标与范围

### 1.1 产品目标

- 学生能通过文字或拍照提出具体学习问题，得到逐层引导，而非首轮直接展示整题答案。
- 图文讲解帮助学生理解概念、图像与解题步骤之间的关系，并支持继续追问。
- 讲解后提供同知识点的练习，完成作答、自评、反馈和重做。
- 学生再次进入产品时，能继续未完成的学习，找到以前保存的题目和笔记。

### 1.2 首期范围

P0 为首期必需功能，P1 为后续增强功能。

| 优先级 | 功能范围 |
| --- | --- |
| P0 | 微信登录、文字与照片提问、题目内容核对、启发式连续对话、知识点直接讲解、图文生成、同类练习、作答与草稿、自评反馈、携题追问、重做、错题本、笔记、手动复习、历史恢复、重命名、归档与恢复 |
| P1 | 练习与讲义 PDF 导出、精细图片裁剪、专用知识点筛选、生成新题进行复测 |

### 1.3 体验版交付

- 管理员在微信小程序后台添加老师为体验成员，分享体验版二维码供其进入使用。
- 老师使用同一套学习功能，以自己的微信身份登录，数据按账号隔离；首期不增加教师端和班级管理。
- 本期不包含班级考试分析、平台成绩导入、自动间隔复习或专项突破计划。
- 服务端持续在线，老师无需安装开发工具或依赖开发电脑即可完成提问、讲解、练习和记录回看。
- 首期交付止于体验版，不安排公开发布与正式版本提审；账号设置、可用服务类目、隐私声明及服务器域名按平台要求完成。

## 2 业务流程

### 2.1 单题求助

新建对话 → 输入问题或上传题目照片 → 核对题干及已知条件 → 确认 → 方向提示 → 学生表达思路 → 追问与步骤纠错 → 学生主动查看完整解析或进入图文讲解 → 同知识点练习 → 作答 → 对照解析自评 → 反馈与重做 → 保存错题。

### 2.2 知识点教学

输入知识点、课堂中没听懂的内容或上传教材及笔记片段 → 必要时澄清讲解范围 → 生成图文讲解 → 针对概念或步骤连续追问 → 生成同知识点练习 → 作答与反馈 → 保存学习记录。

知识点教学可独立开始，澄清范围后直接进入讲解。

### 2.3 直接练习

输入需要练习的知识点及可选难度 → 确认训练范围 → 生成并校验练习 → 独立作答 → 对照自评 → 查看反馈 → 追问、重做或保存。允许跳过图文讲解。

### 2.4 错题复习

进入错题本 → 搜索或按状态筛选 → 查看详情、笔记与历史练习 → 回看讲解或重做练习 → 必要时回到原对话 → 学生手动标记复习状态。

### 2.5 对话归档

最近学习 → 管理对话 → 归档 → 从最近学习和首页继续入口隐藏 → 已归档对话中查看或恢复。查看不自动恢复；发送新消息时自动恢复到最近学习。

## 3 功能需求

### FR-01 登录与个人账号 P0

- 采用微信登录，提供协议、隐私政策和登录帮助入口；未同意协议时提示后再登录。
- 微信身份校验成功后建立应用登录态，学习记录按账号隔离。
- 支持登录取消、失败重试、登录过期后重新登录、退出登录及取消退出。
- 账号面板展示昵称与头像；提供隐私、帮助与退出入口。
- 学习记录归属于个人账号；退出后不能继续访问该账号资料，重新登录同一账号后可恢复。
- 不提供模型名称选择、API Key、模型连接地址和思考强度设置。

### FR-02 学习提问与材料输入 P0

- 支持文字输入、拍照上传与相册选择；一次最多 3 张图片，支持 JPG、PNG、WebP，单张最大 8 MB；本期不支持 PDF 附件。
- 上传后显示缩略预览，允许移除或更换；取消选图不产生空消息。
- 首页提供拍题求助、讲知识点、出练习三个轻量入口，共用文字及“添加附件”输入区；拍题打开图片选择，后两者切换输入意图并聚焦输入，不凭空生成内容。
- 讲知识点可直接描述困惑，也可提供课本、笔记；出练习需提供学习范围或参考题，不要求学生填写标准考点。
- 新建对话中的首次发送建立一段对话，后续回复在该对话继续。图片包含多道题或多个学习范围时，分别列为学习对象，同一时间只围绕当前对象展开教学；衍生练习保留在其所属对象下。
- 轻量切换列表展示各对象及核对状态；切换保留各自的输入草稿、对话、讲解和练习进度，不自动确认或生成材料。可选择按顺序学习，由学生主动进入下一项，不同时展开多题长答案。
- 无关的新问题可另建对话，原对话与已有进度保留。
- 对模糊图片、读取失败、上传失败或超限明确反馈，保留已输入文字供重试。

### FR-03 题目识别与内容确认 P0

- 从照片中提取题干、公式、可辨识图形条件和小问，保留上传原图供对照。
- 识别结果以核对卡展示；学生只需对照原题确认文字、公式和已知条件，可修改题干，不要求填写或核对考点。
- 考点由 Agent 根据题目分析，用于后续讲解与同类练习；缺少考点标签不阻塞教学，不把模型的判断转交学生确认。
- 不确定的文字、符号及图形关系明确提示核对，不将猜测当成题目已知条件。
- 以学生对照原图确认的题干为后续教学依据；确认前不按未核实条件生成解答。
- 先区分多道独立题和同一道题的多个小问：独立题分别建立学习对象；共享题干的小问仍归属于同一题，允许逐问教学。学生只需选择先学哪项，不负责手工拆题或填写考点。
- 默认打开识别出的第一项待核对内容，每项单独确认；核对一题不代表整份图片已确认。识别取消或失败时保留原图及文字，可重试，已存在的学习进度不得被重试覆盖。
- 题干或学生描述的学习范围发生修改后，提示原有讲解与练习需更新；历史内容保留来源，不与新版混用。
- 纯知识点提问澄清范围后直接教学。

### FR-04 Agent 启发式对话 P0

- 默认从引导问题或方向提示开始，根据学生回复逐步进入关键步骤与完整解析。
- 主路径引导学生说出思路，基于其明确表达进行追问，不凭空推断学生的思考过程。
- 上传解题过程时，先转写可识别步骤并请学生确认，再对已确认步骤追问、定位问题和说明修正方法。
- 无法确认某步时说明不确定之处，并请学生补充，不直接断言其错误。
- 学生可以请求进一步提示、换例子、细讲、图文讲解或主动查看完整解析。
- 完整解析默认不主动全部展开；学生主动查看时给予“建议先自己推一遍”的轻提示，允许继续查看。
- 支持连续对话、流式回复、停止生成与失败重试，保留已有消息。
- 回复及学习材料与所属会话、题目和知识点保持对应。

### FR-05 模型生成图文教学 P0

- 基于原题、知识点或课堂内容生成讲解，至少包含概念解释、配图、分步示例和易错辨析。
- 讲解文字、例题和教学配图由模型生成；配图用于解释知识，不仅用于装饰。
- 正文、公式、图中标注与题目条件一致；图片不清晰、标注错误或图文矛盾时，修正后再作为完成内容展示。
- 讲解使用独立阅读页，保留原题、讲解、练习之间的切换及返回原对话的入口。
- 支持“这一步没懂”“换个例子”“再讲细一点”；追问携带当前讲解及对应段落或示例上下文。
- 局部重讲或更换例子后，保存对应讲义及其上下文。
- 讲解结束后提供同知识点配套练习入口；知识点教学同样可以进入练习。
- 文字与配图可分阶段完成，明确展示生成进度；配图失败时提供重试，并允许学生继续已有文字对话。

### FR-06 同知识点练习生成 P0

- 按当前题目或知识点生成 2 至 3 道练习，覆盖基础理解、同类变式，可选综合迁移。
- 每题包含训练知识点、难度、训练目的、题干、参考答案和解析。
- 练习内容与当前学习范围一致，不因随机生成超出学生已确认的条件和范围。
- 发布前校验条件完整性、可解性及题干、答案、解析的一致性；校验未通过时重新生成或提示失败。
- 作答阶段默认隐藏参考答案；学生可通过追问主动查看解析，记录该行为供本次学习回顾。
- 同一套练习再次打开时保持题目不变；刷新或切换页面不重新随机出题。

### FR-07 作答与携题追问 P0

- 支持逐题查看、题号跳转、上一题和下一题，允许先跳过不会的题。
- 支持文字过程、作答照片（每题最多 3 张）、暂时不会标记和方向提示。
- 文字与照片草稿自动保存，离开后回到原题号继续。
- 点击“围绕这题追问”时，携带练习题干、当前作答和所属学习上下文回到对话。
- 对话中提供返回练习入口；返回后保留题号、草稿、照片和当前作答阶段。
- 未作答题提交前提醒；允许继续作答或按未完成提交。

### FR-08 自评反馈与重做 P0

- 提交后展示学生作答、参考答案及解析，让学生逐题选择“独立做对、部分会、还不会”。
- 自评未完成时提示补齐；全部完成后形成反馈与本轮记录。
- 反馈展示本轮自评结果、需要继续巩固的题和建议回顾内容，并支持携题追问。
- 自评为本次主观记录，不表述为系统批改分数、考试得分率或知识点掌握率。
- 如果学生已使用提示或查看解析，反馈中保留相关信息，提醒如实区分独立完成与借助讲解完成。
- 支持查看完整作答、全部重做和仅重做需巩固题；重做前确认当前草稿将被替换。
- 新一轮作答保留旧轮次的题目、文字与图片作答、自评及时间；回看历史不覆盖原记录。
- 重做沿用原题；生成新题复测为 P1。

### FR-09 个人错题与学习记录 P0

- 从对话、讲解或练习结果中保存学习记录，关联原题或知识点、原图、标签、对话、讲解、练习和作答轮次。
- 知识点直接教学可保存为知识点学习记录。
- 同一学习对象重复保存只更新关联内容，不重复新增收藏；同一对话里的不同题可分别收藏、记笔记与标记复习，回看时定位原对象。
- 错题本提供错题、讲解、练习三个查看视角，支持关键词搜索及待复习、已复习筛选；知识点名称可参与搜索。
- 详情页支持查看原题与原图、阅读讲解、继续练习、回到原对话、保存个人笔记和查看练习历史。
- 复习状态由学生手动确认，不因打开材料、保存题目或一次自评正确自动标记已掌握。
- 从错题本移除前确认，只取消收藏，原对话和练习记录保留，可再次保存。
- 对话归档作用于整段对话，与各题错题收藏独立；归档不影响收藏访问。

### FR-10 对话历史与归档 P0

- 最近学习按今天、昨天、更早分组，按最近一次学习活动排序。
- 支持新建对话、恢复历史、修改名称和归档；首页继续学习指向最近活动的未归档对话，说明当前进度，并可恢复最近的阅读章节或练习轮次、题号；没有可恢复位置时回到原对话。
- 归档后隐藏最近入口，完整内容保留；提供已归档列表、查看和恢复。
- 只阅读归档对话不改变状态；在归档对话发送新消息时自动恢复并提示。
- 重新进入会话恢复消息、题目确认状态、已生成材料、作答草稿、自评和相关学习进度。
- 返回与刷新后，携题追问仍关联到原题与原会话。

### FR-11 生成过程与异常反馈 P0

- 识别、答疑、图文生成和练习生成均有真实的进行中、完成和失败反馈。
- 失败可重试；重试不重复新增同一条用户消息或重复保存材料。
- 学生停止生成后保留已完成内容；讲义和题组展示实际完成状态。
- 断网、登录过期或页面被小程序切走后，保留已保存记录，重回时能查看完成结果或继续重试。
- 题干修改后提醒重新生成，生成中的旧版本结果不得覆盖新版本内容。

### FR-12 导出与增强 P1

- 练习可导出题目版 PDF，包含作答留白；答案解析独立成页，可选附带。
- 讲义可导出 PDF，保留正文、公式与图片的对应关系。
- 微信内嵌环境支持 PDF 文件预览或打开。
- 增强能力包括上传裁剪、独立知识点筛选和按原知识点生成新题复测。

## 4 非功能需求

| 类别 | 要求 |
| --- | --- |
| 运行环境 | uni-app 编译的微信小程序体验版，覆盖 iOS 与 Android 微信，以受邀老师的手机独立操作验收 |
| 屏幕适配 | 面向主流手机竖屏；正文可读、操作可触达，长公式支持横向查看；本期不扩展旧款小屏、平板或横屏适配 |
| 性能目标 | 目标为单题识别 10 秒内、对话首段 5 秒内；图文分阶段展示。以实际网络和接口测试结果验收 |
| 内容呈现 | 支持 Markdown、LaTeX 和模型生成图片，长公式、图片预览及失败占位保持可读 |
| 数据保存 | 账号下保存对话、学习材料、错题收藏、笔记及练习记录；本地草稿辅助恢复，不作为唯一正式存储 |
| 数据隔离 | 服务端校验归属，其他账号无法读取或修改个人学习记录；密钥保留在服务端 |
| 结果质量 | 校验题目、图文与解析的一致性，支持错误反馈和重新生成 |
| 稳定性 | 生成失败、重复提交、网络中断和会话过期均可恢复，不丢失已保存内容 |
| 资料管理 | 归档、取消收藏与删除个人数据有不同含义；正式提供使用时应支持用户申请清除本人数据 |

## 5 需求维护

- FR-01～FR-12 编号保持稳定；新增或改变业务行为先修改本文件，再同步设计及验收规格。
- P0 是本期交付范围，P1 不进入本期；精简入口不能删除既定教学、练习和错题能力。
- 页面以连续学习体验为准，原型为视觉参考；允许精简重复操作，不要求逐像素照搬。
- 演示数据只能用于前端交互定稿，不能作为真实教学质量或业务交付通过的依据。
