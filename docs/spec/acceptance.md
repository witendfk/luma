# Luma 验收规格

依据：[PRD](PRD.md)。整理日期：2026-11-06。

**职责：定义怎样才算通过。** 本文只保存稳定的验收条件与场景，实际环境、结果及限制记录在 [验证记录](../delivery/verification.md)。AC 编号沿用原 PRD。

| --- | --- | --- |
| AC-01 | P0 | 微信登录可成功、取消、重试及退出；重新登录后仅恢复本人数据。 |
| AC-02 | P0 | 文字或照片可创建独立学习对话，取消上传不发送空消息。 |
| AC-03 | P0 | 单题识别展示题干、公式及原图供学生核对；考点由 Agent 分析，修改确认后按新内容教学。 |
| AC-04 | P0 | 多小问可选择当前问题；不确定的识别内容明确要求核对。 |
| AC-05 | P0 | 纯知识点或课堂内容可直接获得对应图文讲解。 |
| AC-06 | P0 | 解题默认首轮为方向引导，连续追问有上下文；学生可主动查看完整解析。纯知识点提问可直接解释概念和例子，不把定义当作禁止透露的答案。 |
| AC-07 | P0 | 解题过程照片先转写确认，再基于确认内容定位问题。 |
| AC-08 | P0 | 学生直接请求或Agent依据卡点主动判断，均能生成包含解释、配图、步骤和易错辨析的讲解，不以“图文/图示”关键词为前置；生成状态卡归属当前教学回复，发布后转为可打开对应版本的成果卡。图文与当前条件及解析权限一致，已有适用讲义不重复生成，内联示意不冒充正式讲义完成。 |
| AC-09 | P0 | 换例子与局部重讲针对当前内容生效，并可从历史再次查看。 |

| AC-11 | P0 | 文字及照片作答可保存；携题追问返回后题号与草稿保持。 |
| AC-12 | P0 | 空题提交有提示；逐题自评后形成反馈，清楚标明自评来源。 |
| AC-13 | P0 | 全部或部分重做可完成；历史轮次的题目、作答图片与自评不会丢失。 |
| AC-14 | P0 | 重复保存不重复增加收藏；笔记、复习状态、讲解与练习可从详情访问。 |
| AC-15 | P0 | 归档后从最近学习隐藏，在归档中可查看和恢复，已有收藏不受影响。 |
| AC-16 | P0 | 对话、练习及追问上下文在退出再进入后可恢复，排序反映最近学习活动。 |
| AC-17 | P0 | 识别及生成失败可重试，停止生成或题干更新后不展示错误版本成果。 |
| AC-18 | P0 | 学生端没有模型设置，服务端统一调用 GPT；模型密钥不下发到小程序。 |
| AC-19 | P0 | 真机微信内验证登录、拍照选图、软键盘、页面返回、安全区及重回恢复。 |
| AC-20 | P1 | 讲义及练习可导出 PDF，题目与答案分开，微信中可打开。 |
| AC-21 | P1 | 可在同知识点下生成新题复测，明确区别于原题重做。 |
| AC-22 | P0 | 学生确认理解后可主动生成本次知识图解卡；仅确认理解不自动生成。重复请求不重复生成，结果可放大、收藏回看，失败可重试，不标记掌握率或自动开练习。 |
| AC-23 | P0 | 超出近期消息窗口后，仍能回读当前对象的已讲方法、未解卡点及明确引用的材料；切题、修订或切换练习时不串用旧事实、其他题答案或旧解析授权。 |
| AC-24 | P0 | 首期高中数学的提示、概念教学、纠错及图文场景通过；运行循环与通用工具不硬编码年级/学科准入，数学规则集中配置。本条不要求实现或验收其他学科。 |
| AC-25 | P0 | 已有作答足以判断起点时不重复诊断；连续学习可获得短路线并调整、暂停或跳过，短提示和直接练习不被路线阻塞，不要求学生填写考点。 |
| AC-26 | P0 | 默认不直接公布当前题完整答案；学生不会时能主动解释、配图或示范必要一步，避免反复盘问；图文与卡点一致，图中不提前泄露答案。 |
| AC-27 | P0 | 节点通过有验证题、通过条件、本人作答及帮助记录；自述懂了、跳过或自评不自动通过，不确定判断保留待验证。不展示无依据掌握率、不按80%锁关，不改变正式练习及手动复习记录。 |
| AC-28 | P0 | 学习目标、节点、待验证误解及证据可恢复；切对象或修订题干不串用结果，重复请求和迟到回复不重复推进。学生可主动查看解析或生成总结卡，不受节点验证阻拦。 |

体验版交付另需验证：体验账号可扫码登录，独立完成一次完整学习流程；开发电脑关闭后仍可使用，不同账号的个人学习记录互不混用。

## 2 验证场景

| 验证组 | 样例与标准 | 对应需求 |
| --- | --- | --- |
| 识别与核对 | 清晰题、模糊符号、图形条件、多小问；核对前不按猜测解题 | FR-02、FR-03 |
| 启发教学 | 无思路、错误步骤、坚持看解析、只说懂了；保持阶段边界 | FR-04 |
| 个性化伴学 | 已会内容略过、误解核实、短路线、关键步骤验证及暂停恢复 | FR-04、FR-13 |
| 图文教学 | 单题和课堂知识点、段落追问、换例子；图文与条件一致 | FR-05 |
| 同类练习 | 基础、变式、迁移；可解且答案解析一致，作答前不下发答案 | FR-06 |
| 练习闭环 | 空题提交、照片作答、携题追问、自评、部分重做及旧轮次 | FR-07、FR-08 |
| 记录与账号 | 重复保存、笔记、复习、归档、刷新、退出和另一账号访问 | FR-01、FR-09、FR-10 |
| 异常与版本 | 重复请求、断网、取消、图片失败、任务中改题干、进程重启 | FR-11 |

准备约 20 道高中数学代表题及相应多轮操作场景，开发中加入新发现的失败样例。每个样例记录输入、期望行为、结果、问题和修正后复验情况。核心数据与权限规则需全部通过；识别与教学错误逐项复核修正，不以一次模型回答正确替代整组验证。

Agent 编排至少验证以下操作序列：

| 场景 | 验收重点 |
| --- | --- |
| 拍题 → 核对 → 连续三轮引导 | 确认前不解题；确认后不改变已知条件，不重复问已回答的信息 |
| 知识点 → 图文 → 段落追问 → 换例子 | 可以独立开始；追问目标准确，新讲义保留旧版本 |
| 练习第 2 题 → 提示 → 主动看解析 → 回练习 | 作答草稿保留；权限仅针对第 2 题，记录借助讲解行为 |
| 图文生成中改题干 → 旧任务返回 | 旧任务不能发布为当前结果，当前焦点不被旧任务覆盖 |
| 连点发送、断网、停止、服务重启、显式重试 | 不重复用户消息和成果，不永久占用会话，不把迟到结果改成完成 |
| 图文讲解并出题 → 讲义完成 → 自动继续出题 | 已保存的组合目标没有丢失；长工具结果返回 Agent，恢复不重复调用已成功工具 |
| 提示词中要求忽略规则、模型调用越权工具、超出预算 | 程序拒绝越权与超限；教学语义风险保留样例复验，不只检查输出格式 |

以上运行边界优先用确定性测试验证，教学与识别质量使用真实 GPT 样例评测。运行记录保存所用版本、模型、工具摘要、耗时、消耗及结束原因，不保存或向学生展示内部推理。

### AC-23 教学连续性定向矩阵

本矩阵细化已有连续追问与恢复要求，不新增产品模块。确定性检查验证来源、状态、权限和恢复；真实GPT样例检查提取、找回及解释是否符合原意，不能相互替代。

| 场景 | 通过条件 |
| --- | --- |
| 首次摘要故意遗漏早期“只用图像法”要求 | 有效教学记录仍提供原要求及来源，后续教学遵守；不能只检查摘要JSON合法 |
| 学生连续两次更正同一条件 | 经题干修订/确认使用最新有效版本，保留更正历史；旧条件不因再次摘要复活 |
| 学生错误尝试、随后纠正 | 原错误标明来源和状态，后续不能当成核验结论或重复推荐失败讲法 |
| 未解卡点经历多次压缩及新讲义发布 | 未解决记录仍存在且可回查；不会因12条上限或新章节目录挤掉；明确解决后不继续当未解 |
| 摘要漏掉某方法，学生问“前面第二种方法” | 能定位并读回原文及相关轮次；无法唯一确定时澄清，不新编一段冒充历史 |
| 从段落追问返回对象、切题/版本/练习及解析权限变化 | 对象通用要求可沿用，局部记录不滥用；其他对象、旧版本和未授权答案不能被搜索/摘要带回 |
| 大工具结果缩减后再次依赖其内容 | 从受控引用读回真实结果；工具调用/结果仍配对，写操作不重放，必要失败原因保留 |
| 主对话要求特定讲法，再生成讲义/练习 | 后台收到固定的相关证据和权限快照，结果遵守要求；主对话记住但后台丢失仍判失败 |
| 摘要无效、取消、冲突、超大单条输入及事实容量超限 | 检查点不错误推进，不静默丢必要条件；有界修复后明确失败，原文及已发布内容可恢复 |
| 调用预算与异常恢复 | 发送前考虑本次输入/输出预留；unknown不当免费；缓存不扣窗口，断流/重试不重置总账或重复执行 |

真实样例记录消息/来源、预期事实或动作、实际输出、摘要版本、回读轨迹及消耗。对同一关键语义场景重复抽验并逐次保留结果；不以一次成功、测试总数或“有引用”宣称无损记忆。

### AC-25～28 伴学教学场景

| 场景 | 通过条件 |
| --- | --- |
| 已提供正确思路，只问下一步 | 复用作答证据，直接给相应帮助；不从概念摸底重新开始 |
| 请求解释概念／只要一个提示／直接练习 | 分别响应原意图，不统一强制进入完整诊断与课程 |
| 不会前置知识或连续两次卡住 | 主动解释、配图或示范必要一步，再邀请参与；不连续改写同一个反问；检查真实图示与提示权限 |
| 错把顶点横坐标当最小值 | 以原作答提出疑似误解，用图或对比核实；学生能区分两者并处理新情境后才提出解决，不凭助手讲过自动解决 |
| 独立迁移／提示后完成／看解析后复述／只说懂了 | 分别记录来源和帮助；按预存通过条件评价，不把所有情况都标记独立验证通过；不确定时不推进 |
| 学生跳过验证并进入下一节点 | 可以继续；旧节点保留未验证或跳过状态，正式练习自评与复习标记不变 |
| 暂停重进／切另一题／修订题干／取消后迟到回复 | 恢复正确路线和节点；旧版本证据保留但不冒充新版；同一证据不重复推进 |
| 已表达理解但未参加验证，主动生成总结卡 | 仍可按FR-05生成；未标记掌握，也不自动生图或出题 |

来源、版本、幂等及状态转移使用确定性检查；教学节奏、解释有效性与数学判断使用真实GPT样例复核。保存实际轨迹和限制，不以Skill文件已创建或schema通过代替行为验收。

## 3 验收层级

| 层级 | 验证内容 | 不能替代 |
| --- | --- | --- |
| 前端 mock | 页面点击、输入、跳转、返回、草稿和历史隔离 | 接口持久化、真实识别与教学质量 |
| 本地集成 | 实际 API、数据库、worker、幂等和状态恢复 | 真实微信登录、GPT 与线上运行 |
| 真实依赖 | 微信换码、GPT 视觉/教学/配图、COS、公式及流式内容 | 真机设备行为和个人账号独立试用 |
| 体验版交付 | 主流 iOS/Android 微信、账号隔离、个人账号扫码和线上连续使用 | 不可用模拟器或本机演示代替 |

每条结果注明环境、输入/操作、结果与限制。P0 全部满足且使用者不依赖开发电脑完成闭环后，才能标记业务交付完成；本期不增加小屏、平板或横屏验收。
