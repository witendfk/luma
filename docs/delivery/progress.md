### B01 本轮实际实施

- `LearningSubject` 稳定身份；逐题版本、进度、草稿、收藏及消息，运行与任务固定对象来源。切题只恢复，不生成；生成中禁止切题，旧版本任务发布受校验。
- 保留旧数据的增量迁移：旧会话各建一个首对象，原题/材料/消息/轮次/收藏关联保留；本地数据库已应用。
- 新建对象、焦点、对象修订/确认、进度及练习历史接口；共享详情/进度/作答 DTO；前端逐题导航、草稿恢复和收藏 ID 适配。
- 管理不改变最近学习时间；新消息事务内恢复归档；收藏软取消保留笔记与复习状态。
- 验证使用开发账号、真实 PostgreSQL/API/worker、模型 mock；双题测试记录明确标注 `B01 联调`，不是图片真实识别结果。
- 范围边界：阅读/练习的定位服务与接口基础已提供；正式页面接线和首页精准续学属 B04～B06；练习开始/重做幂等属 B05。B01 不代表 Agent 教学能力或整个服务端完成。
- **提交确认：用户已核对并确认 B01 变更，授权本轮 commit、push；后续任务仍需分别确认。**
