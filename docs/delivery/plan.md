- 继续在 `feature` 开发；每轮先展示实际变更、实施范围和验证结果，经用户确认后才 commit、push；按独立任务点提交并标注所属模块。
- 真实联调按最小闭环逐步进行，不能等服务端全部写完才接页面。

- 每个任务写清代码完成、自动验证和工具实际操作结果；真机结果在交付阶段另记，不混用验证层级。
- 优先修补既有骨架，不重写已验收页面，不扩展产品或设备范围。

## 3 待实施模块

### Agent 能力补齐

依据：[课程与当前代码能力评审](../design/agent-capability-review.md)。以下为待实施任务，不是已完成声明；并入现有模块，不另建全学科平台或重写运行时。

| 顺序 | 任务 | 并入模块 | 完成条件 |
| --- | --- | --- | --- |
| AG01 | 通用学习身份与教学方式 | M03/M04 | 公共身份/运行时保持通用，数学规则为当前唯一内容配置；提示、概念解释和纠错使用合适策略；不新增必填设置；通过高中数学教学样例及扩展边界检查，不开发其他学科 |
| AG02 | 教学进展记忆与按需回读 | M04/M06/M08 | 保存带来源的卡点、已讲方法和待续问题；读取旧材料/旧消息；长对话与切回段落后不遗忘、不跨对象串题；不推断掌握率 |
| AG03 | 内容表达与材料修订 | M06/M07 | 保留已有函数/几何图，增加受控关系/过程图；不将无关内容强塞抛物线模板；局部重讲读取原材料快照；题组 schema 与一次质量修复通过 |
| AG04 | 无进展、截断及断流恢复 | M04/M09，随真实链路补齐 | 成功无进展可拦截；截断参数不执行、截断材料不发布；瞬时错误有限退避且计入总账；心跳/看门狗/数据库对账不重复执行 |
| AG05 | 教学行为场景集 | M04/M09，贯穿 AG01～04 | 约12个高中数学场景覆盖提示、讲解、记忆、不同数学主题及异常；保存真实输出和耗时/用量，关键正确性人工抽查；扩展性检查不增加其他学科交付任务 |

优先完成 AG01 和 AG02 的最小闭环，再按 B03～B06 的页面链路合入 AG03～05。可靠性保护随各调用路径接入，不留到最终交付。教材 RAG、跨会话画像、多 Agent 和多模型路由仍暂缓；对象级教学进展记忆不等于建设长期画像。

### M01 登录与账号（FR-01，真实微信验收在 B07）

- 接入真实微信换码，配置服务端 AppID/AppSecret；验证登录取消、失败、过期、退出和同账号恢复。
- 补齐正式协议与隐私内容，接通已定稿账号面板。
- 关闭开发身份后用两个账号验证隔离，退出清理该账号本地缓存。

完成条件：AC-01、AC-18；真实身份只能访问本人数据。

### M02 首页、导航与对话管理（FR-02、FR-10）

- 将已验收首页/侧栏/管理/归档 UI 切换正式数据。
- 持久保存最近有效阅读章节及练习轮次、题号和阶段，恢复时校验对象与版本。
- 维持学习排序、归档隐藏、查看不恢复、发言恢复；失效目标提示后回有效入口。

依赖：B01 与有效应用登录态（开发阶段允许开发身份）；完成条件：AC-02、AC-15～16，跨重进及服务端恢复正确。

### M03 核对与启发式对话（FR-03～04）

- 将多题对象、逐题确认、编辑版本及消息焦点落库，旧记录迁移为首对象。
- 对齐纯知识点、直接练习、局部追问、携题追问的上下文引用。
- 接通真实提示、完整解析、讲解/练习操作与失败重试；题目确认前不按未核实条件解题。

依赖：R01～R03、M04；完成条件：AC-03～06、AC-16～17，多对象不串题。

### M04 GPT 与 Agent（FR-03～06、FR-11）

- 保留 B02 已接入的真实 GPT、原生工具协议、正文流及预算；后续以新场景增量验证，不重做已有链路。
- 先跑一题三轮引导、知识点直接教学，再跑讲义与练习组合目标的等待/恢复。
- 实现学生可见文本渐进呈现；不得把原始工具 JSON 当回复，不能把 SSE 状态流冒充逐段正文。
- 重复失败检测、输入预算和后台用量已接入；继续补成功无进展检测、截断结果拦截、分类有限重试及 SSE 心跳/客户端静默恢复，预算跨恢复累计。
- 本项是运行时补齐、真实模型集成与行为验证，不是仅配置 GPT 密钥；必须留下真实工具执行轨迹和多轮教学结果。

完成条件：真实模型使用受控工具、根据结果继续并正常停止；预算跨恢复累计，重试不重复保存。

### M05 上传与视觉识别（FR-02～04、FR-07）

- 实现 COS 受限上传、完成校验、文件归属及私有读取，持久保存原图和作答照片。
- 接入 GPT 题目/课本/笔记识别，区分独立题与共享题干小问，保留不确定内容供核对。
- 接入真实解题过程转写，确认后再纠错；练习照片进入所属题目的视觉上下文。
- 处理失败、重试与临时路径失效，保持已输入文字和草稿。

依赖：R01、M03～04、COS 配置；完成条件：AC-02～04、AC-07、AC-11；相机和相册另做真机验证。

### M06 图文教学与阅读（FR-05）

- 接真实正文与结构化教学图解、内容复核和失败重试，成果关联正确对象版本。
- 完成图文教学后，接“理解后的知识图解卡”：学生确认理解并主动点击生成→基于本次教学总结→独立图像模型生成静态总结图→复核→对话缩略图/放大/收藏回看；来源快照去重，不推断掌握、不自动开始练习。新增需求已写入 PRD 和交互设计，尚未实现或验收，不混记为已有教学配图能力。
- 接通文字/图片分阶段状态、失败重试，以及换例子、局部重讲和材料版本保存。
- 实现完整 Markdown/LaTeX 与图片呈现，验证分式、根式、分段函数和长公式。
- 保留已验收章节返回及阅读位置，不因网络接入重置页面状态。

依赖：对象/Agent 与文件存储；照片来源再接 M05 识别。纯文字知识点可先走通；完成条件：AC-05、AC-08～09、AC-22～24。

### M07 练习、作答与自评（FR-06～08）

- 用真实 GPT 生成并复核 2～3 道题，固定题组内容，作答阶段不下发参考答案。
- 接正式文字/照片草稿、防抖与冲突处理；追问返回保留同轮次、同题及输入。
- 接通提交、自评齐全校验、反馈、全部/部分重做与历史只读。
- 保留提示及解析查看记录；自评不转换为系统分数或掌握率。

依赖：对象/Agent 与题组生成；直接练习不依赖先生成讲义。完成条件：AC-10～13、AC-16，跨页面及重进不丢记录，旧轮次只读。

### M08 收藏、笔记与复习（FR-09）

- 收藏、笔记和复习状态改为按学习对象持久保存，支持同一会话多题独立收藏。
- 接正式列表、搜索、视角与复习筛选、详情材料入口和练习历史。
- 保持笔记草稿恢复、取消确认、保存失败保留输入、取消收藏不删除原记录。

依赖：R01、M02、M06～07；完成条件：AC-14～16，多入口收藏去重且不跨对象。

### M09 异常与交付（FR-11、全局）

- 接真实依赖后验证断网、停止、过期、切后台、重复点击、任务失败、旧版本返回和进程重启。
- 开发阶段在本地服务验证异常；交付阶段再部署 HTTPS API、PostgreSQL、worker 与 COS 并配置合法域名。
- 运行约 20 道数学样例及多轮教学回归；完成主流 iOS/Android 真机测试。
- 关闭 mock/开发身份，上传体验版，完成体验成员配置并扫码独立试用。

本地异常验证随 B01～B06 进行；线上和设备验收在 B07。交付完成条件：AC-17～19 及体验版交付门槛，不阻塞当前开发。

## 4 联调顺序

**当前：B04-R 正式图文阅读/追问/局部重讲（含最小 AG01/AG02）→ B03 上传视觉 → B05 正式练习 → B06 学习记录收口 → B04-S 主动总结图解卡 → B07 交付。**

B06 的阅读位置、材料回看随前序链路接线，不等最后一次性接。B04-S 保留 P0，在来源快照稳定后可提前衔接，但不阻塞教学正文和练习。AG03～05 随各批实施；不得先建设全套记忆平台才交付功能。

后续交付：B07 真实微信身份、主流手机设备验证及体验版。当前不要求先部署、不要求手机扫码，也不等待体验版才能联调。

每一步走通页面到服务端的小闭环后再扩展；已有自动回归继续使用，真实教学样例从首条 GPT 链路开始积累。

## 5 三周目标与职责

原三周总投入约 69～84 小时是竞赛版目标预算，不因文档拆分重新起算。R01～R05 已静态评审，剩余排期依据 B02 真实调用延迟与实际开发进展细化，不将原周计划当成已完成证据。

| 阶段目标 | 完成标志 |
| --- | --- |
| 教学主链路 | 真实登录、核对、GPT 引导、上传、图文及基础题组形成可用链路 |
| 学习闭环 | 阅读、追问、作答、自评、重做、收藏、笔记、历史与归档正式落库 |
| 交付与修复 | 真实教学、设备、权限和异常验收通过，个人账号独立使用体验版 |

| 参与方 | 负责内容 |
| --- | --- |
| 开发助手 | 技术设计、实现、自动检查、联调定位、进度和证据更新 |
| 用户 | 产品取舍确认、小程序/云账号及密钥配置、真机操作与个人学习流程的试用反馈 |
| 共同确认 | 真实数学内容质量、体验版交付是否满足竞赛演示需求 |

P1、教材 RAG、全历史自动摘要、长期画像和多 Agent 均不进入当前计划；AG02 的对象级教学进展记录单独按最小范围实施。

本期不接入 Frametell 或动画/视频生成。教学过程使用结构化图解；理解后的知识图解卡使用静态图片，不引入分镜、配音和视频渲染链路。
