## 3 待实施模块

### M01 登录与账号（FR-01，真实微信验收在 B07）

- 接入真实微信换码，配置服务端 AppID/AppSecret；验证登录取消、失败、过期、退出和同账号恢复。
- 补齐正式协议与隐私内容，接通已定稿账号面板。
- 关闭开发身份后用两个账号验证隔离，退出清理该账号本地缓存。

完成条件：AC-01、AC-18；真实身份只能访问本人数据。

### M02 首页、导航与对话管理（FR-02、FR-10）

- 将已验收首页/侧栏/管理/归档 UI 切换正式数据。
- 持久保存最近有效阅读章节及练习轮次、题号和阶段，恢复时校验对象与版本。
- 维持学习排序、归档隐藏、查看不恢复、发言恢复；失效目标提示后回有效入口。

依赖：B01 与有效应用登录态（开发阶段允许开发身份）；完成条件：AC-02、AC-15～16，跨重进及服务端恢复正确。

### M03 核对与启发式对话（FR-03～04）

- 将多题对象、逐题确认、编辑版本及消息焦点落库，旧记录迁移为首对象。
- 对齐纯知识点、直接练习、局部追问、携题追问的上下文引用。
- 接通真实提示、完整解析、讲解/练习操作与失败重试；题目确认前不按未核实条件解题。

依赖：R01～R03、M04；完成条件：AC-03～06、AC-16～17，多对象不串题。

### M04 GPT 与 Agent（FR-03～06、FR-11）

- 在现有单层驱动器接真实 GPT，验证原生工具参数、结果回传及 `respond` 结束协议。
- 先跑一题三轮引导、知识点直接教学，再跑讲义与练习组合目标的等待/恢复。
- 实现学生可见文本渐进呈现；不得把原始工具 JSON 当回复，不能把 SSE 状态流冒充逐段正文。
- 真实测量并调整决策、工具、模型请求、图片、用量与时限上限；验证取消、有限重试和防循环。

完成条件：真实模型使用受控工具、根据结果继续并正常停止；预算跨恢复累计，重试不重复保存。

### M05 上传与视觉识别（FR-02～04、FR-07）

- 实现 COS 受限上传、完成校验、文件归属及私有读取，持久保存原图和作答照片。
- 接入 GPT 题目/课本/笔记识别，区分独立题与共享题干小问，保留不确定内容供核对。
- 接入真实解题过程转写，确认后再纠错；练习照片进入所属题目的视觉上下文。
- 处理失败、重试与临时路径失效，保持已输入文字和草稿。

依赖：R01、M03～04、COS 配置；完成条件：AC-02～04、AC-07、AC-11；相机和相册另做真机验证。

### M06 图文教学与阅读（FR-05）

- 接真实正文、GPT 教学配图、视觉复核及至多一轮修复，成果关联正确对象版本。
- 接通文字/图片分阶段状态、失败重试，以及换例子、局部重讲和材料版本保存。
- 实现完整 Markdown/LaTeX 与图片呈现，验证分式、根式、分段函数和长公式。
- 保留已验收章节返回及阅读位置，不因网络接入重置页面状态。

依赖：对象/Agent 与文件存储；照片来源再接 M05 识别。纯文字知识点可先走通；完成条件：AC-05、AC-08～09。

### M07 练习、作答与自评（FR-06～08）

- 用真实 GPT 生成并复核 2～3 道题，固定题组内容，作答阶段不下发参考答案。
- 接正式文字/照片草稿、防抖与冲突处理；追问返回保留同轮次、同题及输入。
- 接通提交、自评齐全校验、反馈、全部/部分重做与历史只读。
- 保留提示及解析查看记录；自评不转换为系统分数或掌握率。

依赖：对象/Agent 与题组生成；直接练习不依赖先生成讲义。完成条件：AC-10～13、AC-16，跨页面及重进不丢记录，旧轮次只读。

### M08 收藏、笔记与复习（FR-09）

- 收藏、笔记和复习状态改为按学习对象持久保存，支持同一会话多题独立收藏。
- 接正式列表、搜索、视角与复习筛选、详情材料入口和练习历史。
- 保持笔记草稿恢复、取消确认、保存失败保留输入、取消收藏不删除原记录。

依赖：R01、M02、M06～07；完成条件：AC-14～16，多入口收藏去重且不跨对象。

### M09 异常与交付（FR-11、全局）

- 接真实依赖后验证断网、停止、过期、切后台、重复点击、任务失败、旧版本返回和进程重启。
- 开发阶段在本地服务验证异常；交付阶段再部署 HTTPS API、PostgreSQL、worker 与 COS 并配置合法域名。
- 运行约 20 道数学样例及多轮教学回归；完成主流 iOS/Android 真机测试。
- 关闭 mock/开发身份，上传体验版，完成体验成员配置并扫码独立试用。

本地异常验证随 B01～B06 进行；线上和设备验收在 B07。交付完成条件：AC-17～19 及体验版交付门槛，不阻塞当前开发。

## 4 联调顺序

**当前：微信开发者工具 + 本地服务 + 开发身份 → B01 数据契约 → B02 真实 GPT 文字教学 → B03 图片识别 → B04 图文 → B05 练习；B06 学习记录随相关链路接入。**

后续交付：B07 真实微信身份、主流手机设备验证及体验版。当前不要求先部署、不要求手机扫码，也不等待体验版才能联调。

每一步走通页面到服务端的小闭环后再扩展；已有自动回归继续使用，真实教学样例从首条 GPT 链路开始积累。
