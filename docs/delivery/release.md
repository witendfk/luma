# Luma 体验版交付手册

整理日期：2026-11-05。

**职责：说明如何部署、配置、上传和供体验成员扫码使用。** 不作为当前已发布证明；发布状态写入 [进度](progress.md)，验证结果写入 [验证记录](verification.md)。

## 1 交付方式

交付个人主体微信小程序体验版。使用者通过自己的微信身份进入个人学习助手，问题、练习、错题和笔记均归个人账号。

小程序开发者在微信平台添加体验成员并分享二维码；老师也可以作为体验成员试用同一套个人学习功能。成员配置属于微信平台的交付步骤，应用内只有个人学习流程。首期不安排公开发布。

## 2 工具分工

| 工具或环境 | 用途 |
| --- | --- |
| VS Code / Codex | 编辑、编译 uni-app 小程序代码 |
| 微信开发者工具 | 小程序调试、网络检查、真机预览和代码上传 |
| iOS 与 Android 微信 | 登录、拍照、公式、流式、键盘及重回恢复验证 |
| 服务端日志与调用记录 | 定位 Agent 工具、GPT、后台任务和数据库问题 |

用户日常以微信开发者工具和手机试用为主；AI 负责代码与服务端问题定位。模拟器正常不等于真机验收完成。

## 3 配置与交付步骤

1. 完成个人小程序账号设置，取得 AppID，配置开发者与实际功能所需的服务类目、隐私声明及后台要求。
2. 部署服务端、任务进程、数据库与对象存储，配置 HTTPS 和合法域名；AppSecret、GPT 及存储密钥仅部署在服务端。
3. 将 uni-app 编译为微信小程序，导入微信开发者工具，使用真实 AppID；预览并完成手机验证。
4. 在开发者工具上传代码，填写版本号和说明；在后台“版本管理”中将对应开发版本设为体验版。
5. 在后台“成员管理→体验成员”添加体验成员，分享体验版二维码；成员以已添加的微信扫码，登录后独立使用。
6. 体验成员完成新题求助、图文讲解、练习、自评和记录回看；退出再进入可恢复本人记录，其他体验账号的数据不可见。

小程序代码更新后重新上传并设置体验版本。服务端与提示词独立部署，保持与体验版接口兼容；演示期间保留已验证的代码版本和数据备份。首期不执行提交审核及正式发布。

交付包含体验版二维码、已验证版本号、服务地址、简短操作说明和问题反馈方式。服务部署在线，体验成员无需启动开发电脑。微信成员管理和体验版设置参见[微信官方发布说明](https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/release.html)。

## 4 交付前检查

- 服务端及小程序关闭开发身份、模型 mock 和 UI mock，使用真实微信与 GPT。
- API 使用 HTTPS，配置 request/uploadFile/downloadFile 合法域名；开发环境跳过域名检查不能作为交付条件。
- API、worker、PostgreSQL 与对象存储在开发电脑关闭后仍可运行；迁移、密钥与访问权限已验证。
- P0 验收满足，体验成员扫码使用本人身份，不能访问其他账号数据。
- 保存交付版本号、服务地址、二维码、操作说明与反馈方式；服务端更新保持小程序契约兼容。

## 5 部署基线

Docker 从仓库根目录构建：

```bash
docker build -f apps/server/Dockerfile -t luma-server .
```

镜像不包含真实密钥、Git 元数据或本机依赖。部署时分别启动 Next.js API 与 worker，注入相同业务配置，使用已迁移的 PostgreSQL 与私有 COS；确切部署平台及运行参数在部署任务中落实并更新本手册。
