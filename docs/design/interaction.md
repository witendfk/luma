# Luma 交互设计

依据：[PRD](../spec/PRD.md) FR-01～FR-11、FR-13。整理日期：2026-11-06。

**职责：定义页面如何呈现、学生如何操作、跳转后恢复什么。** 功能范围以 PRD 为准，技术实现见其他设计文档，实际点验结果见 [验证记录](../delivery/verification.md)。

## 1 页面与导航

页面参考原型，实现为 uni-app 页面；交互以本文件为当前基线，原型 HTML 不在小程序内嵌。

| 页面 | 主要组件 | 与服务端的交互 |
| --- | --- | --- |
| 登录 | 微信登录、协议、帮助 | 获取应用登录态，处理过期与退出 |
| 新建对话 | 输入框、上传预览、三类快捷入口、继续学习 | 创建会话，上传图片，提交首条消息 |
| 侧边菜单 | 最近学习、管理对话、归档入口、账号 | 获取列表、重命名、归档及恢复 |
| 对话 | 消息、核对卡、提示、成果入口、输入框 | 发送消息、确认题目、接收流式回复和任务状态 |
| 原题 | 题干、标签、原图、编辑面板 | 读取及修改学习对象 |
| 图文讲解 | 章节、公式、配图、追问、配套练习 | 读取指定讲义版本，提交段落追问，创建练习任务 |
| 知识图解卡 | 理解确认、总结缩略图、放大查看、来源讲解及练习入口 | 根据当前学习对象与讲解快照生成并读取已复核总结；重复确认复用 |
| 练习 | 说明、逐题作答、提示、提交、自评与反馈 | 保存草稿，携题追问，提交、自评与重做 |
| 错题本及详情 | 搜索、视角切换、笔记、复习状态、轮次 | 查询收藏，更新笔记及状态，读取历史记录 |
| 已归档对话 | 会话列表、查看、恢复 | 查询归档会话，恢复到最近学习 |
| 账号面板 | 昵称头像、隐私、帮助、退出 | 读取本人资料、注销当前登录态 |

底部导航只在起始页和错题本展示；阅读页返回原对话，练习追问提供明确的返回练习入口。材料中的“这一步没懂”关联最近的章节；学生选定段落时，带上该段标识。

## 2 布局与操作层级

| 区域 | 实施约定 | 检查点 |
| --- | --- | --- |
| 首页 | 适度压缩问候与装饰留白，上移输入区；保留三类轻量入口，选择知识点教学/直接练习后保留其意图 | 常用屏宽首屏可找到输入与发送；快捷入口进入相应流程，不统一绕回单题引导 |
| 侧栏 | 沿用当前 78% 宽度、最大 600rpx；一行标题溢出省略，副行优先显示待核对、讲解已生成、练习未完成等真实状态，时间弱化；管理入口为轻量更多图标 | 空列表、单条和多条均正常；状态无数据时不猜测，不把生成中标成已完成 |
| 核对 | 用户原始消息保留；避免助手再次重复整段题干，详细内容集中在可编辑核对卡。确认后显示简短摘要，可展开查看；修改仍产生新版本并重新确认 | 仅修改题目内容和选择已有小问；考点由 Agent 分析，不要求学生填写或确认；确认前不按猜测条件解题；历史确认卡不再显示可重复提交的过期按钮 |
| 对话动作 | 根据真实教学阶段和已发布材料，突出一个推荐动作，例如写下思路、继续提示、阅读讲解或开始练习；其他动作轻量展示，避免工具栏、回复尾部与材料卡重复堆放相同主入口 | 学生不必每轮在多个同等突出的操作中选择；仍可自由提问、主动看解析；推荐动作不擅自触发未请求的生成任务 |
| 阅读 | 独立内容页，保留原题/讲解/练习切换；概念图解、分步推导、易错辨析分段。保留章节位置、这一步没懂、换个例子和练习入口 | 追问携带讲义版本与章节/段落标识，返回后仍在原章节；已完成文字可读，图片生成或失败状态可见 |
| 练习 | 说明压缩为题数、预计时间及训练目标；竞赛版默认两题，遵循 PRD 的 2～3 题，不硬编码原型三题。作答时突出题目、输入与下一题 | 作答前不展示参考答案；照片、提示、暂时不会和追问作为辅助操作；打印/PDF 仍属 P1，不因原型入口纳入本期 |
| 携题追问 | 对话输入区上方显示当前练习题号、返回练习与结束追问入口；保留轮次、题目、草稿及已上传照片 | 追问和返回不新建作答轮次、不清空答案；结束追问后普通消息不误带旧题上下文 |
| 再次进入 | 首页续学卡说明可恢复任务；最近位置为有效练习时恢复该轮次和题号，为阅读时恢复对应章节，否则回原对话；仅恢复页面，不自动提交、生成或揭示答案 | 以最近一次实际学习位置为准；材料失效或版本变化时说明原因并回到有效入口；归档对话不出现在续学卡 |

推荐动作和续学目标来自持久化状态；不以模型一句自然语言或前端硬编码文本冒充进度。练习草稿优先复用既有服务与缓存；阅读恢复先按章节锚点实现，不引入跨设备精确像素滚动同步。仅在既有数据无法表达这些状态时补最小契约与保存字段。

编辑采用单一文本区的底部面板，不提供考点表单或要求学生手工拆分小问。修改题干后，新版本清空旧的推断标签及小问拆分，保留完整题干供后续重新分析；只切换已有小问时保留题干与标签。候选考点不出现在学生待确认项中。

## 3 完整交互流程

| 场景 | 入口与默认呈现 | 操作、反馈与退出后保留 |
| --- | --- | --- |
| 登录 | 微信登录、协议勾选、帮助 | 未勾选时原位提醒；登录中防重复；失败可重试。固定一屏，插画自适应剩余高度，不产生整页拖动；曲线节点为“提问 → 理解 → 巩固 → 会用”。账号面板不出现模型配置。 |
| 发起学习 | 新建对话输入区；拍题、讲知识点、出练习三个轻入口 | 选图先预览、可移除再发送；取消选图不清空文字；直接讲解/练习保留入口意图。发送失败保留输入。 |
| 图片与多题 | 共用“添加附件”，最多 3 张、单张 8 MB；可仅发图片 | 识别中可取消，失败可重试；就绪后收起缩略区并保留查看原图。多题显示当前序号及轻量底部切换列表，默认第一项待核对，逐项确认。切换保留草稿及各自材料，不自动生成；“这些都想学”只记录顺序学习意愿，由学生进入下一项。 |
| 题目确认 | 原始提问和一张题目核对卡 | 学生只核对文字、公式与条件；考点由 Agent 分析。题干单文本编辑；已有小问可选择；保存后重新确认；确认后摘要可展开。 |
| 引导对话 | 连续消息、底部自由输入和一个推荐动作 | 次要操作采用文字入口；完整解析由学生主动请求；生成中可停、失败可重试。已生成材料从同一会话打开。 |
| 图文阅读 | 原题/讲解/练习轻页签，正文优先；章节目录可定位 | 概念/步骤/易错分段；图点开预览；每段底部只有“这一步没懂”“换个例子”轻入口。章节位置独立保存。未提供图片不伪装为一直生成。 |
| 理解后整理 | 学生确认理解后，主动点“生成图解卡片” | 操作后提示“把刚才的要点整理成一张图”，异步调用独立图像模型生成知识图解卡；成功显示缩略图、考点标题和“查看图解”，失败原位重试。仅给方向提示、尚未有实质讲解时不展示理解确认；不在每条提示后反复询问。允许继续提问或跳过，不弹出强制确认层。 |
| 图解回看 | 从对话成果或已收藏学习记录进入 | 默认适合手机的竖向分区，依次呈现核心结论、图形/公式关系、关键方法、易错点；不照搬参考图的横向多栏密排。轻触放大、可返回来源讲解，配套练习仍由学生主动进入。现有暖白/苔绿风格保持，不增加侧栏一级菜单。 |
| 段落追问 | 回到对话，输入框上方显示讲义名称和当前段落 | 预填具体问题，学生可修改再发送；连续追问沿用同一版本与章节。可返回原段或结束追问；结束后普通对话不再带旧段落。原有未发送草稿不被覆盖。 |
| 练习说明 | 题数、预计用时、训练目标 | 默认两题，不先展示答案；一个“开始作答”。再次进入优先继续当前轮，不能自动新开一轮。 |
| 逐题作答 | 题干、题号、文字输入；上一题/下一题 | 支持跳题、暂时不会、提示、围绕本题追问；文字/照片保持。离开只保存，不提交；空白题提交前可返回补答或按未完成提交。 |
| 练习追问 | 对话明确显示题号与所属轮次 | 预填问题、可编辑；返回同一轮同一题与草稿，不自动揭示答案。结束后不再携带旧题。 |
| 对照自评 | 提交后展示原作答、参考答案与解析 | 逐题选择“独立做对/部分会/还不会”；未评完定位到待评题；完成后出本轮反馈，明确为学生自评。 |
| 重做与历史 | 反馈页提供巩固题重做/全部重做及历史查看 | 重做先确认并新建轮次；旧轮次只读，不覆盖旧作答。没有巩固题时不展示空操作。 |
| 保存与错题本 | 对话/讲解/练习可保存；错题本按错题/讲解/练习看 | 重复保存显示已保存；搜索与复习筛选可组合；详情可编辑笔记、标记复习、回原对话。取消收藏二次确认，保留原对话。 |
| 对话管理 | 最近学习行的轻量更多入口 | 重命名使用原生编辑弹窗，预填原名、校验空值及 60 字上限；归档后从最近列表隐藏，归档页可看可恢复。查看不恢复，发言时恢复并提示；归档不移除收藏。 |
| 重新进入 | 首页续学说明上次停留的阅读章节或作答题号 | 恢复位置和草稿，不自动发送、生成、提交或揭示答案；旧版本材料可读，但明确是历史材料，不冒充当前题目的结果。 |

视觉与状态统一：主体沿用暖白与苔绿，铜色只作编号与提示；次要操作无实色背景，目录/页签/题号用轻下划线或细边线。主要触控区域至少约 44px；底部固定操作不覆盖正文，键盘出现时给输入让位。页面必须有加载、空、失败、重试、生成中与已有内容保留状态。

## 4 照片与转写

- 题目、课本或笔记共用添加附件，最多 3 张、单张 8 MB；可仅图片发送，取消选择不丢文字。
- 解题过程在当前学习对象下添加：照片预览、更换或移除 → 编辑可识别步骤 → 确认后讨论。关闭面板保留草稿，按对象与题干版本隔离；未确认转写不作为纠错事实。
- 练习每题最多 3 张照片，只有照片也算已有作答。追问时可回看本题照片，返回、自评和历史仍保留；仅照片作答显示“已添加作答照片”。
- 图片可进入全屏预览，支持切换、缩放、关闭及失败提示；关闭回原页面，不重置输入或练习阶段。
- 临时图片失效时说明原因，并提供更换或移除；不静默当成有效材料提交。

## 5 收藏、笔记与复习

错题本使用“搜索→错题/讲解/练习视角→全部/待复习/已复习”层级。三个视角是同一收藏记录的不同过滤方式，知识点记录也能保存；讲解与练习视角仅展示具有对应材料的记录。列表采用留白分隔，详情依次呈现原题或最初困惑、材料入口、个人理解和复习信息，不堆叠大实色按钮。

笔记提供编辑、保存、取消及离开后的草稿恢复。未保存修改取消前确认；无草稿使用已保存笔记，刻意清空的草稿仍可恢复；改回原文时清除旧草稿。保存失败保留输入并反馈。手动复习状态独立于练习自评，不自动推导掌握率。

同一学习对象从多个页面收藏只产生一条记录；移除仅取消收藏，原对话、笔记、练习和历史保留，重新收藏可继续使用。归档与收藏相互独立。历史轮次只读打开，不切换、覆盖或提交当前轮次；找不到本机历史时明确提示并回当前轮次。材料仅能从所属学习对象打开，不得跳到其他题的讲解或练习。

## 6 续学与返回

- 首页读取最近有效学习位置：阅读到章节，练习到轮次、题号、照片草稿或自评阶段；失效目标提示后回原对话。
- 打开续学只恢复页面，不自动发送、生成、提交或揭示答案。
- 重命名、归档和恢复归档不改变学习时间；真实学习活动才更新最近学习排序。
- 归档从最近学习和首页续学隐藏；只查看不恢复，发送新消息时恢复并提示。归档与各对象收藏相互独立。
- 历史轮次只读，回当前轮次不得带入旧照片、旧自评或覆盖当前草稿；重做以空白新轮次开始。

## 7 视觉与设备范围

暖白、苔绿及少量铜色细节；统一线性图标、留白和轻文字操作。新建对话不加实色背景，学习操作不堆叠大型胶囊按钮。登录插画曲线保留“提问、理解、巩固、会用”四节点。

不设置与新建对话重复的“学习首页”菜单，不常驻展示年级、学科及教材版本；教学范围按需在对话中明确。账号头像与昵称水平对齐，移动端不提供模型配置。使用真实小程序导航，不重复绘制原型的模拟宿主胶囊。

登录页与首页内容未溢出时不产生整页滚动；侧栏只有列表真实溢出才滚动。面向主流手机竖屏，处理底部安全区与软键盘，不扩展旧款小屏、平板或横屏。

原型位置见 [原型说明](../../../产品原型/README.md)。已定稿交互不因服务端旧契约反向退回单对象或丢失草稿。

## 8 伴学进展与短验证

在现有对话内呈现，不新增课程首页、一级菜单或模式选择页。Agent建议连续学习目标后，显示一条轻量目标与当前节点摘要；点击展开短路线，节点用细线、状态点与简短文字表示，不堆大按钮或百分比仪表盘。简单求助无路线时不留空占位。

节点状态采用PRD FR-13文案。“待巩固”与“已跳过”可继续操作，“已通过本次验证”不简写为“已掌握”。展开后可跳过、暂停或调整目标；跳过反馈只说明已保留进度，不提示扣分或未达80%。旧消息里的进展作为当时快照，当前摘要以正式保存状态为准。

短验证作为一条对话内容，学生沿用输入框作答，可选轻量选项或“暂时跳过”；不要求新开练习页或提交一套题。评价先展示具体依据与下一步建议，再更新节点；失败或不确定时保留作答，不突然显示通过。正式练习仍使用已有逐题作答与自评页面。

需要图文时沿用现有讲解与段落追问入口，图围绕当前卡点，不因路线存在自动生成整份讲义或展开完整解析。教学正文保持流式，结构化进展完整校验落库后更新；等待时不显示假节点或假进度。理解后总结图解卡的主动生成入口与既有条件保持。

重进时简短显示上次目标和当前节点，不重复完整诊断；切题按对象恢复，旧题干路线只读显示来源失效，不能用旧通过状态冒充新题进展。节点学习进度与阅读章节、练习题号分别保存，返回原段或原题仍遵守§6。
